# Подписание документов — скриншоты

Дата съёмки — в имени файла (21.09 или 27.09). Экраны демо-стенда, данные вымышленные (контрагенты маскируются).

| Папка | Что показано |
|---|---|
| `1-send-for-signing` | вкладка «Подписание» карточки сделки, мастер «Отправить на подпись» (шаг «Документ»: из шаблона / свой PDF) |
| `2-documents-and-inbox` | «Мне на подпись», «Документы» (статусы: подписан, на подписании, частично, отклонён, нет соглашения об ЭДО), телефон |
| `3-signer-flow-public` | внешний подписант по ссылке: ознакомление → код из СМС → подписано; отказ с причиной; неверный код; ссылка недействительна (десктоп и телефон) |
| `4-verification` | публичная проверка подписи по идентификатору и по файлу (нашёлся / «файл не совпадает ни с одной подписью») |
| `5-edm-agreements` | соглашения об электронном документообороте (ЭДО) |

## Что могло измениться после съёмки

Компоненты подписания правились 27–28.09: мелкие правки формы («замечания тестировщика»: обозначение обязательных
полей, подсказки), кнопка скачивания проверяемого файла в карточке документа, подсказки verify-by-file, пакетная
загрузка карточек документов. Логика и общий вид те же, но по пикселям кадры 21.09 старше кадров 27.09 — для
финальной презентации лучше использовать кадры 27.09 (`crm-signing-…`, `send-wizard-…`, `deal-tab-signing-…`,
`inbox-mine-…`), остальные пересъёмка освежит.
